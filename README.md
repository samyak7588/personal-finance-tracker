# Personal Finance Tracker — CSE Mini Project

A desktop application built with **Python (Tkinter GUI)** and **JSON file storage** to track
personal income and expenses.

## Features
- Add income / expense transactions (type, category, amount, note)
- Auto date-time stamping
- Live summary: total income, total expense, running balance
- Color-coded transaction table (green = income)
- Delete transactions
- ASCII category bar-chart report (income + expense breakdown)
- Export full report as `.txt`
- Persistent storage in `data/transactions.json`

## Tech Stack
| Layer    | Technology |
|----------|------------|
| Language | Python 3   |
| GUI      | Tkinter (built-in, no installs needed) |
| Storage  | JSON flat-file persistence |

## How to Run
```bash
python finance_tracker.py
```
No external packages required — Tkinter ships with Python.

## Project Structure
```
finance-tracker/
├── finance_tracker.py     # main app (data layer + logic + GUI)
├── README.md
└── data/
    ├── transactions.json  # created automatically on first add
    └── report.txt         # generated by "Export Report"
```

## Concepts Demonstrated (viva points)
- OOP: `FinanceApp` class encapsulating GUI state and handlers
- Separation of concerns: data layer / business logic / presentation
- File I/O: JSON serialization & deserialization
- Exception handling for corrupt files & invalid input
- Event-driven programming (Tkinter callbacks)
- Data aggregation & sorting for reports

## Suggested Viva Questions
1. Why JSON over CSV? → supports structured records, easy round-trip via the `json` module.
2. How is data validated? → amount must be positive float; type restricted to two values.
3. What happens if the data file is deleted/corrupted? → app falls back to an empty list gracefully.
